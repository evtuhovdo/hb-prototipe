# Health Bridge - Навигация по страницам

## Описание
Навигационная страница со списком всех страниц проекта Health Bridge.

## Файлы
- `index.html` - навигационная страница со списком ссылок
- `pages/main.html` - главная страница для неавторизованных пользователей
- `styles.css` - стили CSS
- `script.js` - JavaScript функциональность
- `README.md` - этот файл

## Как открыть
1. Откройте файл `index.html` в браузере для навигации
2. Или сразу перейдите к `pages/main.html` для главной страницы
3. Или запустите локальный сервер:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (если установлен http-server)
   npx http-server
   ```

## Дизайн-система
- **Цвета:** Бело-голубая палитра (по требованию заказчика)
  - Primary: #4A90E2 (основной голубой)
  - Primary Dark: #357ABD (тёмно-голубой)
  - Primary Darker: #2C5F9A (ещё темнее)
  - Primary Light: #E8F4F8 (светло-голубой)
  - Primary Pale: #B8D4F0 (бледно-голубой)
  - Gradients: Только голубые оттенки
  - Glassmorphism: rgba(255, 255, 255, 0.1) с blur
- **Шрифт:** Inter (Google Fonts) с весами 400-800
- **Сетка:** 8px базовая единица
- **Анимации:** Cubic-bezier transitions (0.4, 0, 0.2, 1)
- **Тени:** Многоуровневая система теней (sm, md, lg, xl, 2xl)
- **Скругления:** 16px (стандарт), 24px (большие элементы)

## Адаптивность
- Desktop: ≥ 1200px
- Tablet: 768px - 1199px  
- Mobile: < 768px

## Технические особенности
- **CSS Custom Properties** для легкой кастомизации
- **Intersection Observer API** для анимаций при скролле
- **Backdrop-filter** для glassmorphism эффектов
- **Conic gradients** для вращающихся элементов
- **CSS Grid** и **Flexbox** для современной раскладки
- **Clamp()** для адаптивной типографики
- **CSS Animations** с keyframes
- **Smooth scrolling** и parallax эффекты

## Созданные страницы

### 🏠 Главная страница (index.html)
- **Назначение:** Публичная страница для неавторизованных пользователей
- **Функции:** Hero-блок, категории, партнёры, как это работает, CTA
- **Особенности:** Современный дизайн с анимациями и glassmorphism

### 🔐 Страница авторизации (pages/login.html)
- **Назначение:** Вход в систему для авторизованных пользователей
- **Функции:** Форма входа, переключение видимости пароля, информация о преимуществах
- **Особенности:** Двухколоночный макет с информационными карточками

### 📊 Личный кабинет (pages/dashboard.html)
- **Назначение:** Главная страница авторизованного пользователя
- **Функции:** Статистика, рекомендуемые предложения, боковая навигация
- **Особенности:** Адаптивная сетка, интерактивные карточки офферов

### 📄 Детальная страница оффера (pages/offer-detail.html)
- **Назначение:** Подробная информация о конкретном предложении
- **Функции:** Описание, контакты, промокод
- **Особенности:** Sticky sidebar, копирование промокода, breadcrumbs

### 📂 Страница категории (pages/category.html)
- **Назначение:** Просмотр всех предложений в конкретной категории
- **Функции:** Фильтрация, поиск, сортировка, пагинация
- **Особенности:** Гибкая система фильтров, адаптивная сетка

### 👤 Профиль пользователя (pages/profile.html)
- **Назначение:** Управление личными данными и настройками
- **Функции:** Редактирование профиля, смена пароля, история, уведомления
- **Особенности:** Табы навигации, валидация форм, переключатели

### ❤️ Избранное (pages/favorites.html)
- **Назначение:** Управление сохранёнными предложениями
- **Функции:** Просмотр, удаление, экспорт, фильтрация
- **Особенности:** Анимации удаления, пустое состояние, массовые действия
