# Как правильно запустить проект Health Bridge

## ❌ НЕПРАВИЛЬНО - Не открывайте файлы напрямую!

**НЕ ДЕЛАЙТЕ ТАК:**
```
file:///Users/evtuhovdo/www/аналитика/проект Хрупина Кирилла/верстка/pages/main.html
```

**Проблемы при прямом открытии:**
- Относительные пути не работают
- Навигация ломается (появляется `pages/pages/login.html`)
- JavaScript может не работать
- CORS ошибки

## ✅ ПРАВИЛЬНО - Используйте локальный сервер

### Вариант 1: Python (рекомендуется)
```bash
cd "/Users/evtuhovdo/www/аналитика/проект Хрупина Кирилла/верстка"
python3 -m http.server 8000
```

Затем откройте в браузере:
```
http://localhost:8000/index.html
```

### Вариант 2: Node.js (если установлен)
```bash
cd "/Users/evtuhovdo/www/аналитика/проект Хрупина Кирилла/верстка"
npx http-server -p 8000
```

### Вариант 3: PHP (если установлен)
```bash
cd "/Users/evtuhovdo/www/аналитика/проект Хрупина Кирилла/верстка"
php -S localhost:8000
```

## 📱 Тестирование навигации

1. **Откройте:** `http://localhost:8000/index.html`
2. **Перейдите на главную:** `http://localhost:8000/pages/main.html`
3. **Нажмите "Войти"** - должно перейти на `http://localhost:8000/pages/login.html`
4. **Проверьте все ссылки** - навигация должна работать корректно

## 🔧 Если сервер не запускается

### Проверьте Python:
```bash
python3 --version
```

### Если Python не установлен, установите:
```bash
# macOS
brew install python3

# Или скачайте с python.org
```

### Альтернативные порты:
```bash
python3 -m http.server 3000
python3 -m http.server 8080
```

## ⚠️ Важно!

- **Не открывайте файлы через file://**
