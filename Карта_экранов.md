# Карта экранов Health Bridge

## 🏠 Публичные страницы (для всех пользователей)

### 1. Главная страница (main.html)
- **Назначение:** Лендинг для неавторизованных пользователей
- **Функции:** 
  - Hero-блок с призывом к действию
  - Сетка категорий (6 категорий) - клик ведёт на all-offers.html с фильтром по категории
  - Блок партнёров
  - Популярные предложения (6 карточек)
  - **НОВОЕ:** Кнопка "Все предложения" → переход на all-offers.html
  - Кнопка "Войти в систему" → переход на login.html
  - Как это работает (3 шага)
  - CTA-блок с формой заявки на регистрацию
- **Навигация:** → login.html, → all-offers.html, → offer-detail-public.html

### 2. Все предложения (all-offers.html) ⭐ НОВАЯ
- **Назначение:** Просмотр всех предложений с поиском и фильтрами
- **Функции:**
  - Поиск по тексту (название, описание, партнёр)
  - Фильтр по категории (6 категорий)
  - Фильтр по региону (9 регионов + "Вся Россия")
  - Сортировка (новые, популярные, по скидке, по сроку, по алфавиту)
  - **НОВОЕ:** Поддержка URL параметров (?category=health/sport/etc)
  - **НОВОЕ:** Автоматическая фильтрация при переходе с главной страницы
  - Сетка предложений (12+ карточек)
  - Счётчик результатов
  - Кнопка "Показать ещё"
- **Навигация:** ← main.html, → offer-detail-public.html

### 3. Страница авторизации (login.html)
- **Назначение:** Вход в систему
- **Функции:**
  - Форма входа (email + пароль)
  - Переключение видимости пароля
  - Ссылка "Забыли пароль?"
  - Информационные карточки о преимуществах
  - Форма восстановления пароля
- **Навигация:** ← main.html, → dashboard.html (после входа)

### 4. Личный кабинет (dashboard.html)
- **Назначение:** Дашборд для авторизованных пользователей с полными предложениями
- **Функции:**
  - Приветствие пользователя
  - Статистика (активные предложения, избранное, использовано)
  - Поиск и фильтрация предложений
  - Полная информация о предложениях (промокоды, контакты)
  - Кнопки "Получить скидку" и "Добавить в избранное"
- **Навигация:** ← login.html, → category.html, favorites.html, profile.html

### 5. Детали предложения (публичная) (offer-detail-public.html)
- **Назначение:** Просмотр предложения для неавторизованных пользователей
- **Функции:**
  - Описание предложения
  - Информация о партнёре
  - Контакты
  - Призыв к авторизации для получения промокода
- **Навигация:** ← main.html, ← all-offers.html, → login.html

## 👤 Личный кабинет (для авторизованных пользователей)

### 6. Страница категории (category.html)
- **Назначение:** Просмотр предложений в конкретной категории
- **Функции:**
  - Заголовок категории с описанием
  - Поиск по предложениям
  - Фильтры по подкатегориям
  - Сортировка
  - Сетка предложений
  - Breadcrumbs
- **Навигация:** ← dashboard.html, → offer-detail.html

### 7. Детальная страница оффера (offer-detail.html)
- **Назначение:** Подробная информация о предложении с промокодом
- **Функции:**
  - Полное описание
  - Промокод с кнопкой копирования
  - Контакты партнёра
  - Кнопка "Добавить в избранное"
  - Breadcrumbs
- **Навигация:** ← category.html, ← dashboard.html, → favorites.html

### 8. Избранные предложения (favorites.html)
- **Назначение:** Управление сохранёнными предложениями
- **Функции:**
  - Список избранных предложений
  - Удаление из избранного
  - Экспорт списка
  - Фильтрация
  - Пустое состояние
- **Навигация:** ← dashboard.html, → offer-detail.html

### 9. Профиль пользователя (profile.html)
- **Назначение:** Просмотр личных данных и смена пароля
- **Функции:**
  - Просмотр ФИО, email, компании (только чтение)
  - Смена пароля
- **Особенности:** Упрощённый интерфейс, только необходимые функции
- **Навигация:** ← dashboard.html

## 📱 Webview мобильного приложения

### Технические требования:
- **Адаптивность:** Все страницы оптимизированы для мобильных устройств
- **Touch Events:** Поддержка жестов и касаний
- **Deep Linking:** Прямые ссылки на офферы
- **Native Bridge:** Интеграция с нативным приложением
- **Push Notifications:** Уведомления через нативное приложение
- **Viewport:** Корректное отображение в webview

### Поддерживаемые платформы:
- iOS 12.0+
- Android API 21+ (Android 5.0+)
- Только портретная ориентация
- Время загрузки ≤ 3 сек на 3G
